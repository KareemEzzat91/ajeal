# Ajeal 👨‍👩‍👧‍👦

A dual-role Flutter application for managing child development and therapy plans while keeping parents connected to their child's progress.

Ajeal connects **practitioners and parents** through shared child profiles, therapy goals, session planning, progress tracking, daily notes, and real-time communication.

## ✨ Key Features

- 👥 **Dual-Role Experience** — Dedicated workflows for practitioners and parents.
- 🧒 **Child Profiles** — Centralized personal, health, assessment, and care information.
- 🎯 **Goal-Based Care Plans** — Create and manage development goals using a predefined goal library.
- 📅 **Session Scheduling** — Generate and manage therapy sessions based on selected goals and dates.
- 📝 **Session Tracking** — Record tasks, ratings, notes, and outcomes for every session.
- 🤖 **AI Progress Analysis** — AI-assisted insights for understanding development progress.
- 📓 **Daily Notes** — Add and manage ongoing child-development observations.
- 💬 **Practitioner–Parent Chat** — Firebase-backed communication with real-time updates.
- 📊 **Progress Dashboard** — Give parents a clear view of goals, sessions, and development progress.
- 🌐 **Arabic & English** — Localized experience for both languages.
- 🌙 **Light & Dark Themes** — Flexible visual experience.

## 🔄 Core Flow

```text
Role Selection
      ↓
Authentication
      ↓
Child Profile
      ↓
Goals & Care Plan
      ↓
Session Schedule
      ↓
Session Outcomes
      ↓
Progress Tracking
      ↓
Parent Dashboard & Communication
```

## 🛠️ Tech Stack

- **Flutter & Dart**
- **BLoC / Cubit** — State management
- **Firebase Authentication** — User authentication
- **Cloud Firestore** — Cloud data and real-time communication
- **Gemini** — AI-assisted progress analysis
- **SharedPreferences** — Local preferences
- **GetX / Navigator** — Application navigation

## 🚀 Getting Started

```bash
git clone https://github.com/KareemEzzat91/ajeal.git
cd ajeal
flutter pub get
flutter run
```

For Firebase features, configure the required Android/iOS Firebase files before running the application.
